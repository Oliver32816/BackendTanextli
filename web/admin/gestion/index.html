Buenas prácticas

  • Asigna admin o superusuario solo a quien lo necesite.
  • Las contraseñas no se pueden ver: se guardarán cifradas. Si alguien la olvida, usa Restablecer (disponible en la fase 3) para generar una temporal.
  • Eliminar una cuenta borra también su progreso. Esta acción no se puede deshacer.
  • Este panel solo existe dentro de la red privada de Tailscale para las personas autorizadas.
