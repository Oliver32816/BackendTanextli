Registrar usuario

Mínimo 8 caracteres. Compártela por un medio seguro.

Buenas prácticas

  • Asigna admin o superusuario solo a quien lo necesite.
  • Las contraseñas no se pueden ver: se guardan cifradas. Si alguien la olvida, usa Restablecer (botón de llave) para generar una temporal; se le pedirá cambiarla al entrar.
  • Eliminar una cuenta borra también su progreso. Esta acción no se puede deshacer.
  • Este panel solo existe dentro de la red privada de Tailscale para las personas autorizadas.
